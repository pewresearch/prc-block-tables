This folder is for blocks.

## Data Table blocks

| Block name | Title | Description |
| --- | --- | --- |
| `prc-block/data-table-controller` | Data Table Controller | Context provider; passes data to child table blocks. |
| `prc-block/data-table-render` | Data Table Render | Renders the sortable table output. |
| `prc-block/data-table-filter` | Data Table Filter | Button filter for sheet or column filtering. |
| `prc-block/data-table-filter-select` | Data Table Filter Select | Dropdown grouping multiple filter buttons. |
| `prc-block/data-table-key` | Data Table Key | Legend/key for the data table. |

If you have admin components, include in the includes folder as `/includes/inspector-panel`.
